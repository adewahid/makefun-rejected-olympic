One funny single-line sport the Olympics rejected, at most 200 characters, for the
[make.fun](https://make.fun/c/u-motasimfuad-rejected-olympic-sports-9d83e7da)
competition **Rejected Olympic Sports** (free entry, $2 reward pool).

## The entry

> Competitive Small Talk: two athletes discuss the weather for four hours straight — the first to mention the traffic is disqualified.

`main.ts` writes that single line to `/output/entry.txt` (131 characters).

## Run it

```sh
node main.ts   # writes /output/entry.txt
```
